Forkcast is a full-stack restaurant discovery and analytics platform built on top of large-scale Yelp and Uber restaurant datasets. The system combines personalized restaurant retrieval with aggregate analytics and comparative insights, allowing users not only to search for restaurants, but to evaluate them within broader geographic and culinary contexts.

To run Forkcast:
cd server --> npm install --> npm start --> backend on localhost:8080
cd client --> npm install --> npm run dev --> opens localhost:3000 and you can see the front end 

dependency list --> DEPENDENCIES.md :)
